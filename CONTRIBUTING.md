# Contributing

Keep the profile read/analyze/plan/draft/local-artifact only. Use synthetic data. Add a failing test before changing executable finance logic, run it to confirm the expected failure, implement minimally, then run every offline suite. Do not add credentials, dependencies, network paths, live-system integrations, recurring jobs, rates, benchmarks, tax rules, account mappings, or real financial data. Update schemas, templates, docs, and eval coverage together. Leave changes uncommitted unless a maintainer explicitly requests a commit.
